# 空间音源圆盘 Demo 开发计划

## Context

这是一个主打「精心声音环境」（冥想方向）的产品验证阶段：用户在圆盘中心，把雨声、篝火等声源拖到圆盘四周，组成可保存、可分享的声音方案。仓库 `new-dailylift` 是全新 monorepo，未来容纳 app/网站/API，本期只交付 iOS demo。技术路线已在 STUDY.md 中与 GPT 讨论定型：**iOS 自建 Expo 本地模块（Swift 封装 AVAudioEngine + AVAudioEnvironmentNode，HRTF 双耳渲染）**，界面用 **Skia + Gesture Handler + Reanimated**，方案只存配置 JSON。已确认：素材程序生成、分享走剪贴板 + 分享面板（无后端）。

## 技术栈

- pnpm monorepo（`.npmrc` 设 `node-linker=hoisted`，Expo 官方 monorepo 建议）
- `apps/mobile`：Expo 最新稳定 SDK（`create-expo-app` TypeScript 模板），development build，不支持 Expo Go
- 音频：Expo Local Module（Expo Modules API / Swift），`AVAudioEngine` + `AVAudioPlayerNode`（每声源）+ `AVAudioEnvironmentNode` + `.HRTFHQ`，素材单声道，`sourceMode = .spatializeIfMono`
- UI：`@shopify/react-native-skia`（圆盘、光晕）+ `react-native-gesture-handler`（拖动）+ `react-native-reanimated`（动画）+ `phosphor-react-native`（图标）+ `zustand`（方案状态）
- 存储/分享：`@react-native-async-storage/async-storage`、`expo-sharing`、`expo-clipboard`
- 测试：vitest（只测 `src/domain` 纯逻辑，不测 RN 组件）

## 关键设计

**Swift 模块 API**（demo 单场景，无 sceneId）：
`prepare()` 启动引擎/设置 AVAudioSession.playback/listener(0,0,0)；`loadSource(id, uri, loop)`、`playSource(id)`、`stopSource(id)`、`setSourcePosition(id, x, y, z)`、`setSourceVolume(id, volume)`、`unloadSource(id)`、`stopAll()`。每个 playerNode 设 `renderingAlgorithm = .HRTFHQ`、`distanceParams`（参考 0.5m / 最大 5m / rolloff 1）——距离衰减由原生层做，JS 不重复计算。

**坐标映射**（`domain/position.ts`）：圆盘中心为原点，屏幕上方 = -z（前方）、右 = +x，圆盘半径 R px ↔ 最大 4m；拖动位置 clamp 在圆盘内。skia 盘面画同心距离圈，中心画听者光点（呼吸动画）。

**交互**：点按列表项 → 声源加到圆盘随机位置并立即播放；盘内节点可拖动（实时 `setSourcePosition`）、点按弹小面板（音量滑条 / 暂停 / 移除）。声源节点用 RN View（图标+中文名），Skia 画盘面与光晕（读 Reanimated shared values）。

**方案 JSON**（`domain/scheme.ts`）：
`{ version: 1, name, sources: [{ instanceId, soundId, x, z, volume }] }`，导入时校验拒绝非法数据（version/soundId 白名单/数值范围）。

**分享/导入**：保存到 AsyncStorage（多方案）；「分享」→ 写 cache 临时 .json → `expo-sharing` 系统面板，同时提供「复制到剪贴板」；「导入」→ 读取剪贴板解析校验。

**素材生成**（`scripts/generate-sounds.ts`）：纯 Node 写 16-bit PCM 单声道 44.1kHz WAV，6 个约 8s 无缝循环（首尾交叉淡化）：雨声（粉噪+雨滴脉冲）、溪流（带通噪声调制）、篝火（噪声底+噼啪）、风铃（正弦衰减音簇）、风声（低通噪声起伏）、鸟鸣（随机啁啾）。内置素材用 `Asset.fromModule(require(...)).localUri` 传原生。
